# Сайт замовлення шкільного харчування

Laravel 12 + Filament v4. Технічне завдання — [ТЗ_шкільне_харчування_v2.md](ТЗ_шкільне_харчування_v2.md).

Коренева папка сайту — **`public_html`** (перейменована зі стандартної `public`).
Document root на хостингу має вказувати саме на неї.

## Локальне оточення

PHP в OSPanel зупинився на 8.1, тому для проєкту стоїть окремий **PHP 8.3** у `C:\php83`
(разом із Composer). OSPanel не чіпали — він далі обслуговує інші домени й дає MariaDB.

`C:\php83` доданий у PATH користувача, тож у **новому** терміналі працюють `php` і `composer`.

```powershell
php artisan serve          # http://localhost:8000
npm install && npm run dev # фронтенд
```

База — MariaDB з OSPanel (`school_food`, користувач `root` без пароля).
Перед роботою треба запустити OSPanel.

## Точки входу

| Адреса | Хто | Реалізація |
|---|---|---|
| `/` | Будь-хто: меню й кошик відкриті без входу | Blade + Livewire, мобільний UX |
| `/supplier` | Постачальник | Filament-панель, дані ізольовані по `supplier_id` |
| `/admin` | Адміністратор школи | Filament-панель, повний доступ |

## Ключові рішення

- **Ціна = сума обраних страв.** Комплекс — спосіб показу, а не товар. У замовлення потрапляють окремі страви.
- **Ціна страви глобальна** (лежить у картці страви). У позицію замовлення пишеться знімок ціни й назви — подальші зміни в меню не чіпають оформлені замовлення.
- **`order_lines` — центральна сутність.** Скасування змінює статус рядка, не видаляє його.
- **Дедлайни рахуються на сервері** для кожної пари «постачальник + дата»: спершу виняток на дату, потім відносне правило дня тижня.
- **Кошик у БД**, спільний для всіх постачальників; один номер на весь чек.
- **Вхід просимо лише на оформленні.** Гість дивиться меню й збирає кошик (кошик прив'язаний
  до токена в сесії), а після входу гостьовий кошик переноситься в кошик учня.
- **Час** зберігається в UTC, відображається в Europe/Kyiv.
